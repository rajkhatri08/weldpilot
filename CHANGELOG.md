# Changelog

All notable changes to this project are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Project skeleton: uv package with a src layout for Python 3.12 and the subpackages `data`, `detect`, `cause`, `act`, `edge`, `eval` and `report`.
- `weldpilot info` command: package version, Python version, git commit (with `-dirty` for uncommitted changes) and data root.
- Settings from the environment: `WELDPILOT_DATA` sets the data root (default `./data`).
- Ruff, mypy (strict) and pytest config; pre-commit hooks; GitHub Actions CI.
- README, ADR template, ADR 0001 (Python and tooling), datasheet outline and the Apache-2.0 licence.
- `weldpilot data verify` command: one SHA-256 fingerprint over the Al5083 release (train/, test/ and README; `.DS_Store` files and the `al5083/` copy are skipped). `--record` saves it to `configs/dataset.yaml`; otherwise a mismatch is an error.
- `weldpilot data index` command: checks the fingerprint first, then writes frame, segment and session tables to `data/derived/` from paths, labels and training PNG headers, with strict checks on names and labels. Test images are never opened.
- `weldpilot data composition` command: markdown tables of the release by split and by class, flagging classes with fewer than two train-only sessions.
- Datasheet Composition section, generated by `weldpilot data composition`.
- `pandas-stubs` and `types-PyYAML` in the dev group, for mypy.

### Changed

- `git_sha` moved from `weldpilot.cli` to the new `weldpilot.provenance`.
